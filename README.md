# Flexbox: parte 2

Exercícios resolvidos sobre `flex-grow`, `flex-shrink`, `flex-basis`, o atalho `flex`, `min-width`, `order` e `align-self`, fechando com a montagem de uma página com miolo.

## Conteúdo

- [`respostas.md`](respostas.md): respostas das 29 questões, com os cálculos.
- [`respostas.txt`](respostas.txt): as mesmas respostas em texto simples, na ordem do estudo dirigido.
- [`exemplos/pagina-com-miolo.html`](exemplos/pagina-com-miolo.html): página com topo, menu, texto e rodapé (questões 24 a 26).
- [`exemplos/calculos.html`](exemplos/calculos.html): os cálculos de grow, shrink e `flex: 1` x `flex: auto` (questões 7, 8, 10, 11 e 16).

## Como usar

Abra os arquivos `.html` direto no navegador. Não há dependências.

## Resumo rápido

- **`flex-basis`**: tamanho de partida do item no eixo principal.
- **`flex-grow`**: quanto da sobra o item recebe, proporcional aos pesos.
- **`flex-shrink`**: quanto o item cede quando falta espaço.
- **`order`**: muda a posição visual sem mexer no HTML.
- **`align-self`**: exceção ao `align-items` do pai, para um único item.
