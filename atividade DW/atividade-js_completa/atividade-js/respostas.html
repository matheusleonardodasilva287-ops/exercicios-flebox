Checkpoint
  1. 1. Na aba Console.
  2. 2. O defer faz o navegador ler todo o HTML antes de executar o script. Quando o script procura um elemento (por exemplo #mensagem), ele já existe na página. Sem o defer, o script rodaria antes e não encontraria nada (null).

Etapa 1 — O que é JavaScript

Checkpoint
  1. 1. Quando um dos lados do + é texto, o operador concatena: o 3 vira texto e o resultado é "53". O - só existe para números, então o JavaScript converte "5" em número e calcula 5 − 3 = 2.
  2. 2. A multiplicação é feita antes da soma: 2 + 3 * 4 = 2 + 12 = 14. Com parênteses, a soma vem primeiro: 5 * 4 = 20.

Etapa 6 — Funções

script.js

function dobro(x) {
  return x * 2;
}

const media = (lista) => {
  let soma = 0;
  for (const n of lista) {
    soma += n;
  }
  return soma / lista.length;
};

console.log(dobro(21));
console.log(media([8, 6.5, 9, 4]));

Saída: 42 e 6.875. No console do navegador: dobro(5) dá 10 e media([10, 6]) dá 8.

Checkpoint
  1. 1. Imprime undefined. A função calcula a + b, mas não devolve nada porque falta o return. Correção: return a + b;, que imprime 5.
  2. 2. 
    function ehPar(n) {
  return n % 2 === 0;
}
  3. 3. console.log(x) apenas mostra o valor no console e não devolve nada para quem chamou. return x devolve o valor a quem chamou a função (que pode guardá-lo ou usá-lo em contas) e encerra a função.

8.2 a 8.5 — script.js completo

const NOTA_MINIMA = 6;

function calcularMedia(n1, n2) {
  return (n1 + n2) / 2;
}

function notaValida(n) {
  return !Number.isNaN(n) && n >= 0 && n <= 10;
}

const botaoCalcular = document.getElementById("calcular");
const resultado = document.getElementById("resultado");

botaoCalcular.addEventListener("click", () => {
  const texto1 = document.getElementById("nota1").value;
  const texto2 = document.getElementById("nota2").value;
  const n1 = Number(texto1);
  const n2 = Number(texto2);

  if (texto1 === "" || texto2 === "" || !notaValida(n1) || !notaValida(n2)) {
    resultado.textContent = "Informe duas notas entre 0 e 10.";
    return;
  }

  const media = calcularMedia(n1, n2);
  let situacao;
  if (media >= NOTA_MINIMA) {
    situacao = "Aprovado";
  } else {
    situacao = "Abaixo da média";
  }

  resultado.textContent = `Média: ${media.toFixed(1)} - ${situacao}`;
});

8.3 e 8.4 — testes no console

calcularMedia(8, 7) → 7.5; calcularMedia(10, 5) → 7.5; calcularMedia(6, 6) → 6. notaValida(5) → true; notaValida(10) → true; notaValida(11) → false; notaValida(-1) → false; notaValida(NaN) → false.

Sobre n1 + n2 / 2: a divisão acontece antes da soma. Com 8 e 6 dá 8 + 3 = 11, e a média correta é (8 + 6) / 2 = 7.
