Etapa 0 — Preparando o ambiente

Arquivo index.html

<!DOCTYPE html>
<html lang="pt-BR">
<head>
<meta charset="UTF-8">
<title>Atividade JavaScript</title>
<script src="script.js" defer></script>
</head>
<body>
<h1>Atividade de JavaScript</h1>
<p id="mensagem">Aguardando o JavaScript...</p>
</body>
</html>

Arquivo script.js

console.log("Olá, JavaScript!");

Salvar os dois arquivos (Ctrl+S), abrir o index.html no navegador, apertar F12 e abrir a aba Console. A mensagem Olá, JavaScript! aparece ali.

Checkpoint
  1. 1. Na aba Console.
  2. 2. O defer faz o navegador ler todo o HTML antes de executar o script. Quando o script procura um elemento (por exemplo #mensagem), ele já existe na página. Sem o defer, o script rodaria antes e não encontraria nada (null).
  3. 3. O navegador não encontraria o arquivo codigo.js (erro 404 no console) e nenhum código seria executado, então a mensagem Olá, JavaScript! não apareceria.

Etapa 1 — O que é JavaScript

ExpressãoResultado observado
2 + 35
"Web" + " I""Web I"
"5" + 3"53"
"5" - 32
2 + 3 * 414
(2 + 3) * 420
Checkpoint
  1. 1. Quando um dos lados do + é texto, o operador concatena: o 3 vira texto e o resultado é "53". O - só existe para números, então o JavaScript converte "5" em número e calcula 5 − 3 = 2.
  2. 2. A multiplicação é feita antes da soma: 2 + 3 * 4 = 2 + 12 = 14. Com parênteses, a soma vem primeiro: 5 * 4 = 20.

Etapa 2 — Variáveis e tipos

script.js

const escola = "IFC Concórdia";
let nota1 = 8.5;
let aprovado = false;
let sobrenome;

console.log(typeof escola);
console.log(typeof nota1);
console.log(typeof aprovado);
console.log(typeof sobrenome);

nota1 = 9;
console.log(nota1);
escola = "Outra";

Saída no console: string, number, boolean, undefined, 9 e depois o erro vermelho da última linha. Trocando para let nota1 = "8.5";, o segundo typeof imprime string.

Checkpoint
  1. 1. string, number, boolean, undefined.
  2. 2. TypeError: Assignment to constant variable. Acontece porque escola foi declarada com const, que não permite trocar o valor depois de definido.
  3. 3. Válidos: nota_final e $total. Inválidos: 3nota (começa com número), nota-final (hífen não é permitido) e class (palavra reservada da linguagem).
  4. 4. Imprime 16: idade começa em 15 e recebe 15 + 1.

Etapa 3 — Operadores, conversão e texto com variáveis

script.js

const a = 7;
const b = 2;
console.log(a + b, a - b, a * b);
console.log(a / b);
console.log(a % b);
console.log(a ** b);

const nome = "Ana";
console.log(`Olá, ${nome}! ${a} dividido por ${b} é ${a / b}.`);

console.log(Number("7.5") + 1);
console.log("7.5" + 1);
console.log(Number("abc"));

Saída esperada no console

9 5 14
3.5
1
49
Olá, Ana! 7 dividido por 2 é 3.5.
8.5
7.51
NaN
Checkpoint
  1. 1. As 8 linhas de saída estão acima.
  2. 2. Number("7.5") + 1 converte o texto em número e soma: 8.5. "7.5" + 1 concatena e dá o texto "7.51". Como o valor de um campo de formulário chega como texto, é preciso converter com Number() antes de fazer contas.
  3. 3. 10 % 3 = 1; 2 ** 3 = 8; 10 / 4 = 2.5.

Etapa 4 — Condicionais

script.js

const temperatura = 25;

if (temperatura >= 30) {
  console.log("Calor");
} else if (temperatura >= 20) {
  console.log("Agradável");
} else {
  console.log("Frio");
}

console.log(5 == "5");
console.log(5 === "5");
console.log(0 == false);
console.log(0 === false);
temperaturaMensagem
25Agradável
30Calor
19Frio
20Agradável

As quatro últimas linhas imprimem true, false, true, false.

Checkpoint
  1. 1. Com 20 aparece Agradável, pois 20 >= 30 é falso e 20 >= 20 é verdadeiro. Com 30 aparece Calor, pois 30 >= 30 é verdadeiro e o primeiro bloco já é executado.
  2. 2. true, false, true, false. Recomenda-se === porque o == converte os tipos antes de comparar e dá resultados surpreendentes (5 == "5" e 0 == false são verdadeiros). O === exige mesmo valor e mesmo tipo.
  3. 3. nota >= 0 && nota <= 10
